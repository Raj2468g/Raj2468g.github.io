# Ganapathi Raj — Personal Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript. No framework, build step, paid theme or backend is required.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a browser.

For a local development server, run this from the project folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish free with GitHub Pages

Your GitHub profile: https://github.com/Raj2468g

### Recommended: publish as your main profile website

1. Sign in to GitHub.
2. Create a **public** repository named exactly `Raj2468g.github.io`.
3. Upload the contents of this folder (`index.html`, `style.css`, `script.js`, and `README.md`) to the repository root. Do not upload only the ZIP file.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to deploy. Your site should appear at:
   `https://Raj2468g.github.io`

GitHub Pages setup guide: https://docs.github.com/en/pages/quickstart

## Update the website

Edit `index.html`, `style.css` or `script.js`, commit the changes to the `main` branch, and GitHub Pages will publish the update automatically.

## Notes

- The site uses Google Fonts from fonts.googleapis.com. If those fonts are unavailable, it falls back to system sans-serif and monospace fonts.
- No analytics, tracking scripts, contact-form backend or third-party embeds are included.
