# Ganapathi Raj — Advanced Personal Portfolio

A responsive, dark premium portfolio for GitHub Pages, built with plain HTML, CSS and JavaScript.

## Included
- Responsive dark/emerald layout and mobile navigation
- Animated visual toolkit bars (illustrative focus indicators, not proficiency scores)
- Expandable project details
- DevOps and Machine Learning resume PDFs in `assets/`
- Contact form that prepares an email in the visitor's email application
- No framework, build step, paid hosting or backend required

## Preview locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named exactly `Raj2468g.github.io`.
2. Upload the contents of this folder to the repository root. Upload the `assets` folder too; do not upload only the ZIP.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. When deployment completes, visit `https://Raj2468g.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart

## Before publishing
- The profile image is currently a GR monogram placeholder. Replace it with a professional headshot when ready.
- Verify your LinkedIn URL and public email address.
- Check the contents of both resume PDFs and choose which version to share for each role.
- Add project repository links after confirming the repositories are public and correct.
- The contact form uses `mailto:`. It opens the visitor's email app and does not submit to a server. For a true hosted form with server-side delivery, connect a service such as Formspree or Getform and add its endpoint.
- The skill bars are visual design accents, not measured proficiency ratings.

## Updating
Edit `index.html`, `style.css` or `script.js`, then commit and push changes to `main`. GitHub Pages republishes automatically.
